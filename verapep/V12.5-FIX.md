# VERAPEP v12.5 — vial rendering fix

- Fixed catalogue/product-card legacy CSS collision that converted vial label layers into 74px circles.
- Vial layers now use div-based markup and cannot be hit by legacy `.product-card__visual span` rules.
- Neutral photorealistic bottle is loaded as a CSS background, eliminating lazy-image/fallback visibility issues.
- Full bottle is scaled to fit each product visual without clipping.
- Product name remains sourced from `product.name` in the existing catalogue/database data.
- Strength remains sourced from the selected/first available product variant.
- Colour remains derived from existing `discoveryGoals` / category mapping.
- Backend/database files are not modified by this fix.
