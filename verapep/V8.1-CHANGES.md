# VERAPEP v8.1

Frontend refinement release built on v8.

- Added crisp vector crystal bubbles in the liquid hero. They are independent of the compressed motion video and remain sharp at all screen sizes.
- Reduced the soft ripple opacity and made the high-resolution poster image responsible for most visual detail.
- Added one shared light aqua visual system to the homepage, support, guide, My Pages, checkout, order tracking, admin and every product page.
- Kept backend APIs, catalogue data, inventory, admin synchronisation, cart and checkout logic unchanged.
