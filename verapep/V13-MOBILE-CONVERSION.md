# VERAPEP V13.0 — Mobile conversion pass

Focus: make the existing visual direction shop faster and more clearly on phones without redesigning desktop.

- Cart is visible directly in the mobile header.
- Hero is shorter; the primary shopping CTA dominates on mobile.
- Mobile hero uses a much smaller responsive WebP asset.
- Empty ratings are hidden instead of repeating “No ratings yet”.
- Delivery estimates only appear when a product is actually available to order.
- Relevance sort places currently available products first.
- Catalogue cards are more compact and the primary action gets visual priority.
- Product finder repeats goal choices inside the finder and moves priority controls under Advanced filters.
- Ask Vera is reduced on mobile to navigation + floating launcher.
- Preview/test language is consolidated and less repetitive while remaining explicit that checkout is not live.
- Checkout shows a readable current-step label on mobile.
