VERAPEP FRIENDS TEST
====================

1. Skapa ett PRIVAT repository på GitHub.
2. Lägg upp alla filer från denna mapp där.
3. Logga in på Render och koppla GitHub.
4. New > Blueprint, välj repositoryt.
5. Render läser render.yaml.
6. Fyll i ADMIN_EMAIL och ett nytt ADMIN_PASSWORD.
7. Deploy.

Full guide: RENDER-DEPLOY-SV.md
