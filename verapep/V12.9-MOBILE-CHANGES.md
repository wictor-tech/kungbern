# VERAPEP V12.9 — Mobile-first storefront pass

Date: 2026-08-11

## Goal
Make the friend-test experience feel intentionally designed for phones (360–430 px), without changing the backend, catalogue data, admin logic, desktop design, or Render configuration.

## Main changes
- Rebuilt the mobile header/menu with 44–54 px touch targets and 16 px search/input text.
- Rebalanced the homepage hero for the first mobile viewport: readable headline/body, stronger CTAs, controlled bubble artwork and compact trust proof.
- Reworked goal selection into a swipeable, snap-aligned mobile strip.
- Rebuilt Featured Peptides as large mobile shopping cards instead of miniature desktop cards.
- Enlarged vial presentation and all product typography on phone widths.
- Rebuilt reassurance cards to readable mobile cards rather than 100 px desktop strips.
- Simplified finder/progress layouts and improved button/chip touch targets.
- Changed the full catalogue to one product per row on phones for readability and purchase clarity.
- Improved Ask Vera panel/launcher positioning and safe-area handling.
- Improved product detail mobile layout, variant cards, product facts and mobile buy bar.
- Changed checkout mobile flow to keep the active form before the order summary, with full-width actions and 16 px fields.
- Improved My Pages, Product Guide, Ask Vera, Order and Admin small-screen layouts.
- Added safe-area spacing and reduced risk of horizontal overflow.

## Technical scope
- New stylesheet: `assets/v12-9-mobile.css`
- Added `theme-v12-mobile` body class to all 8 HTML templates.
- Added the v12.9 mobile stylesheet last in the cascade on all 8 HTML templates.
- No backend, SQLite schema, API, catalogue, price, inventory or Render configuration changes.
