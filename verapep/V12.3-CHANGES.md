# VERAPEP v12.3 — Unified premium glass vials

Frontend-only update.

## What changed

- All 84 catalogue products now use one consistent photorealistic glass-vial design.
- The physical vial render is based on the latest supplied VERAPEP glass-vial artwork.
- Product name is inserted dynamically from storefront/database data.
- Displayed strength is derived from the currently preferred/first variant and formatted for the vial label.
- The same vial renderer is used on homepage/featured cards, the full catalogue, product detail pages and cart drawer.
- Long product names automatically scale down on the label rather than requiring individual image files.
- Existing five product PNG mappings remain in the project for reference, but public product cards now use the unified dynamic renderer.

## Backend

No backend, database, catalogue or product-content source files were changed.
